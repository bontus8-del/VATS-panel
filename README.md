# 📞 ВАТС Панель — MTC Exolve

Настольное приложение для удобного управления виртуальной АТС **MTS Exolve**:
просмотр сотрудников и номеров, включение/выключение приёма звонков,
настройка маршрутизации, массовая привязка номеров к логинам.

Приложение работает **напрямую** с вашей ВАТС через официальный API и не
требует установки Python или каких-либо библиотек — достаточно скачать и
запустить один файл.

---

## 🖥 Системные требования

- Windows 7 / 8 / 10 / 11
- Подключение к интернету
- Действующий аккаунт MTS Exolve с услугой **Интеграция**

## 🚀 Быстрый старт

1. Скачайте файл `ExolvePanel.exe` со страницы [Releases](../../releases).
2. Поместите его в любую удобную папку (например, `C:\ExolvePanel\`).
3. Запустите двойным кликом.
4. Программа создаст еще 1 JSON файл для хранения домена и RPS, если файл удалить то при повторном запуске и вводе домена файл пересоздастся.

**Первый запуск может занять 3–5 секунд** — это нормально: файл распаковывает
внутренние ресурсы во временную папку. Последующие запуски быстрее.

### ⚠️ Windows SmartScreen

При первом запуске Windows может показать окно **«Windows защитила ваш
компьютер»**. Это происходит со всеми приложениями без платной цифровой
подписи. Нажмите:

> **Подробнее** → **Выполнить в любом случае**

Если антивирус удаляет файл — добавьте его в исключения. Исходный код
приложения открыт, вы можете его проверить.

## 🔑 Что нужно перед первым использованием

Для работы приложения нужны две вещи: **домен ВАТС** и **API-ключ**.

### 1. Домен ВАТС

Откройте личный кабинет ВАТС Exolve в браузере. Адресная строка будет
выглядеть примерно так:

```
https://exolve123456.vats.exolve.ru/...
```

**Домен** — это часть между `https://` и первым `/`:

```
exolve623969.vats.exolve.ru
```

Скопируйте его — он понадобится в шапке приложения.

### 2. API-ключ

API-ключ выдаётся в личном кабинете ВАТС. Чтобы его получить:

1. **Проверьте, что подключена услуга «Интеграция».**
   Перейдите в раздел **Финансы** в личном кабинете и убедитесь, что услуга
   активна. Если её нет — подключите.

2. Перейдите в **Настройки** → **Интеграции**.

3. Прокрутите страницу в самый низ до блока **«Ваша CRM»**.

4. Нажмите **«Подключить»**.

5. Задайте произвольное имя интеграции — например, `Панель ВАТС`.

6. **Скопируйте появившийся ключ** и обязательно нажмите **«Сохранить»**.

## 🎯 Как пользоваться программой

При первом запуске введите **домен ВАТС** и **API-ключ** в поля шапки:

- **🌐 ДОМЕН ВАТС** — например, `mtt665573.vpbx.mtt.ru`
- **🔑 КЛЮЧ (X-API-KEY)** — Ключ из ЛК
- **⚙ МАКС. RPS** — максимальное число запросов в секунду (по умолчанию 5) значения больше 5 могут работать нестабильно (возможна блокировка по превышеню лимита запросов)

После ввода ключ автоматически сохранится в защищённом хранилище Windows
(Credential Manager), а домен — в файле `vats_config.json` рядом с приложением.
**При следующих запусках вводить их заново не нужно.**

### 👤 Вкладка «Список пользователей»

Список сотрудников ВАТС с именами, логинами, внутренними номерами и ролями.

- **Обновить** — загрузить актуальный список.
- **Поиск** — поле ввода справа, фильтр по имени, логину или внутреннему номеру.
- **Правый клик по строке** — скопировать логин, имя или всю строку.

### 📞 Вкладка «Номера ВАТС»

Список телефонных номеров с их маршрутизацией и статусом приёма звонков.

Для каждого номера показано:

| Колонка | Что означает |
|---|---|
| **Номер** | Сам номер телефона |
| **Название** | Название номера (если задано) |
| **Маршрут** | Куда направляются входящие вызовы: на сотрудника `👤`, на отдел `👥`, меню, расписание и т.д. | 
| **Статус** | ● Включен / ○ Отключен — принимает ли номер звонки |
| **Действие** | Кнопка «Вкл» / «Выкл» для этого номера |
### Если номер живет в карусели, маршрут будет отображаться как "Не задан"

**Кнопка в строке:**

- Если номер **включён** → нажатие **выключает** приём звонков.
- Если номер **отключён** и у него есть маршрут → **включает** без изменений.
- Если номер **отключён** и маршрута нет → откроется окно выбора маршрута.

**Массовые действия:**

Отметьте чекбоксами нужные номера (выделение сохраняется при переходе между
страницами). В панели над таблицей появятся кнопки:

- **☑ Выделить всё / ☐ Снять выделение** — быстрое выделение отфильтрованных.
- **⋮** — дополнительное меню: выделить только включённые, только отключённые
  или снять выделение.
- **✅ Включить / ❌ Выключить** — одна кнопка, которая меняет своё название
  в зависимости от того, что выбрано больше. Нажатие открывает окно выбора
  маршрута (для включения) или сразу выключает номера.

**Окно выбора маршрута** позволяет направить звонки на:

- **👤 сотрудника** — начните вводить логин, имя или должность;
- **👥 отдел** — начните вводить название или ID отдела.

### 🔄 Вкладка «Замена номеров»

Массовая привязка номеров к логинам сотрудников (одна строка = одна пара
«логин + номер»).

- Начните вводить логин или номер в поле — появятся подсказки.
- Можно вводить значения вручную, без выбора из подсказок.
- **➕ Добавить строку** — создать новую пару.
- **🚀 Поменять номера** — отправить все пары на выполнение.

По завершении внизу появится уведомление, а подробный отчёт — во вкладке
**«RAW Ответ (Debug)»**.

### 📋 Вкладка «RAW Ответ (Debug)»

Техническая информация: сырые ответы сервера, отчёты о массовых операциях,
тексты ошибок. Полезно, если что-то пошло не так — эти данные можно
переслать разработчику или в поддержку.

## ❓ Частые вопросы

**Ключ перестал работать / пишет «Неверный X-API-KEY (401)».**
Ключ мог быть отозван или истёк. Создайте новый в ЛК ВАТС и введите в поле
ключа в шапке.

**Приложение пишет «Некорректный домен или ошибка соединения».**
Проверьте:
- правильность домена (без `https://` и без `/` в конце);
- есть ли интернет;
- открывается ли ЛК ВАТС в браузере.

**Массовая операция идёт медленно.**
Скорость ограничена полем **⚙ МАКС. RPS** в шапке. Это защита от блокировки
на стороне сервера. Значение можно увеличить до 20, но не рекомендуется ставить больше 10 без необходимости и в часы высокой звонковой нагрузки.

**Как удалить сохранённый ключ?**
Откройте «Панель управления» → «Диспетчер учётных данных» → «Учётные данные
Windows» → найдите запись `exolve_panel` и удалите её. Либо просто введите
новый ключ в шапке приложения.

**Программа упала / зависла.**
Закройте окно и запустите заново. Если повторяется — откройте вкладку
**Debug**, скопируйте содержимое и пришлите в Issues.

## 🔒 Безопасность

- API-ключ хранится в защищённом хранилище Windows (**Credential Manager**),
  а не в открытом файле.
- Все запросы идут по HTTPS с проверкой сертификата.
- Ключ **никогда** не пишется в логи, файлы настроек или текст ошибок.
- Приложение не отправляет ваши данные куда-либо, кроме ВАТС MTS Exolve.
